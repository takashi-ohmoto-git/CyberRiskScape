## 脅威モデリングの実行トリガー チェックリスト

### モデル差分で自動判定できる項目

- [ ] **T1 新しい信頼境界** — データが新しいネットワークセグメント、テナント分離境界、または権限境界を越える
- [ ] **T2 新しい外部インターフェース** — インターネット向け API、Webhook、gRPC エンドポイント、コールバック URL、公開 SDK
- [ ] **T3 新しい認証／認可の仕組み** — 新しいログインフロー、トークン種別、mTLS、RBAC モデル、サービス ID、証明書管理
- [ ] **T5 機密データが新しい経路を通る** — 顧客データ、シークレット、暗号鍵、PII が、これまで扱っていなかったコンポーネントを通過する
- [ ] **T6 新しいサードパーティ連携** — 顧客データを受け取る、または処理する外部ベンダーの SDK、API、サービス
- [ ] **T7 エージェントの能力拡大** — 新しいツール・MCP サーバー・サブエージェントへの委譲・記憶の追加、自律性や権限の引き上げ
- [ ] **T8 モデル・学習データ・RAG ソースの変更** — 利用する LLM の変更、ファインチューニング／学習データ、RAG の参照先の追加・変更

### 人（または AI レビュアー）による確認が必要な項目（モデル差分では自動判定できません）
